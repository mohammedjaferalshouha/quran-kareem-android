# الأمان | Security

## الإبلاغ

يرجى عدم نشر تفاصيل ثغرة حساسة في بلاغ عام قبل توفير فرصة لمعالجتها. استخدم قسم الأمان في المستودع إن كان متاحًا، أو افتح بلاغًا مختصرًا دون بيانات استغلال حساسة.

## التحقق من الإصدار

كل إصدار رسمي يجب أن يتضمن:

- ملف التطبيق الموقّع.
- بصمة الملف.
- رقم الإصدار.
- ملخص التغييرات.

خوارزمية البصمة:

`SHA-256`

## Security reports

Please avoid publishing sensitive exploit details in a public issue before maintainers have had an opportunity to respond. Use the repository security contact mechanism where available, or open a minimal issue without sensitive reproduction data.

Official releases should publish the signed APK, version number, changelog, and SHA-256 checksum.
